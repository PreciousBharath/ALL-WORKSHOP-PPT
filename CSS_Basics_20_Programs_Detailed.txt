CSS BASICS - 20 PROGRAMS WITH LINE-BY-LINE EXPLANATIONS
=======================================================

FORMAT USED FOR EVERY PROGRAM
1. Complete program
2. Line-by-line explanation in very simple English
3. Short result/what to observe

PROGRAM 1: Text Color
---------------------

COMPLETE CODE:
<!DOCTYPE html>
<html>
<head>
<style>
h1 {
    color: blue;
}
p {
    color: green;
}
</style>
</head>
<body>
<h1>CSS Basics</h1>
<p>CSS changes text color.</p>
</body>
</html>

LINE-BY-LINE EXPLANATION:
Line 1: <!DOCTYPE html>
Explanation: Declares HTML5.
Line 2: <html>
Explanation: Starts the document.
Line 3: <head>
Explanation: Starts the head section.
Line 4: <style>
Explanation: Starts an internal CSS section.
Line 5: h1 {
Explanation: Selects all h1 elements.
Line 6:     color: blue;
Explanation: Starts the h1 rule.
Line 7: }
Explanation: Sets the text color to blue.
Line 8: p {
Explanation: Ends the h1 rule.
Line 9:     color: green;
Explanation: Selects all p elements.
Line 10: }
Explanation: Starts the p rule.
Line 11: </style>
Explanation: Sets paragraph text to green.
Line 12: </head>
Explanation: Ends the p rule.
Line 13: <body>
Explanation: Ends the style section.
Line 14: <h1>CSS Basics</h1>
Explanation: Ends the head.
Line 15: <p>CSS changes text color.</p>
Explanation: Starts visible content.
Line 16: </body>
Explanation: Creates the heading.
Line 17: </html>
Explanation: Creates the paragraph.

RESULT / WHAT TO OBSERVE:
The heading becomes blue and the paragraph becomes green.
