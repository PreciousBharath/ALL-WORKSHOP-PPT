# Generative AI Master Practical Suite

A comprehensive, end-to-end interactive Python web application powered by Streamlit covering all core Generative AI practical concepts.

## 🌟 Modules Included
1. **Prompt Engineering Studio**: Zero-Shot, Few-Shot, Chain-of-Thought (CoT), Persona prompting & side-by-side latency/token benchmarking.
2. **RAG & Vector DB Engine**: Document chunking, TF-IDF / Cosine Similarity vector store, context retrieval with source attribution.
3. **Multimodal Vision AI**: Image analysis, captioning, object detection, and Visual QA.
4. **Text-to-Image Generation Lab**: Dynamic canvas artwork synthesizer with custom prompt enhancer and style presets.
5. **Autonomous ReAct Agent**: Thought-Action-Observation loop with live tools (Calculator, Web Search, Execution Sandbox).
6. **Code Generation & Sandbox**: Code synthesizer, unit test generator, and safe Python execution sandbox.
7. **Speech & Audio AI**: Text-to-Speech synthesis waveform preview and Speech-to-Text transcriber simulator.
8. **Safety & Guardrails**: PII (Email, Phone, SSN) redaction engine and Prompt Injection / Jailbreak detection shield.
9. **Model Evaluation & Embeddings**: 2D PCA embedding space visualizer and BLEU/ROUGE metric evaluator.

## 🚀 How to Run
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run unit tests
python -m pytest tests/test_genai.py

# 3. Launch Streamlit Application
streamlit run app.py
```
