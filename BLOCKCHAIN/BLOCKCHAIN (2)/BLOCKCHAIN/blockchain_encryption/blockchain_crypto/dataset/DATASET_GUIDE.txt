🔒 QUICK START TEST PROCEDURE
=============================

Step 1: SELECT A FILE
─────────────────────
Choose any file from the dataset. Recommended for beginners:
→ sample_document.txt (simplest)
→ financial_report.csv (data format)
→ user_credentials.json (structured data)

Step 2: ENCRYPT THE FILE
────────────────────────
1. Go to "Encrypt" section
2. Click "Choose a file" button
3. Navigate to: blockchain_crypto/dataset/
4. Select your test file
5. Enter password (use suggested passwords above)
6. Confirm password
7. Click "🔒 Encrypt File" button
8. Wait for success message
9. Download encrypted file (button appears after encryption)

Step 3: VERIFY IN BLOCKCHAIN
────────────────────────────
1. Go to "Blockchain" section
2. Click "🔄 Refresh Ledger"
3. Verify your encryption operation is recorded
4. Click "✅ Verify Chain"
5. Confirm "Blockchain is valid" message

Step 4: DECRYPT THE FILE
────────────────────────
1. Go to "Decrypt" section
2. Click "Choose encrypted file"
3. Select the .enc file you downloaded
4. Enter original filename
5. Enter the password (same one used to encrypt)
6. Click "🔓 Decrypt & Download"
7. File downloads automatically

Step 5: VERIFY INTEGRITY
────────────────────────
1. Go to "Tools" section
2. Select original file
3. Click "🔐 Calculate Hash"
4. Note the SHA-256 hash
5. Repeat for decrypted file
6. Verify hashes match exactly
