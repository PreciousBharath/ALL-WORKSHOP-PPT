-------------------------------

PASS/FAIL CRITERIA
==================
✓ PASS: File successfully encrypted and can be decrypted
✓ PASS: Hash of original and decrypted files match
✓ PASS: Operation recorded in blockchain
✓ PASS: Blockchain verification succeeds
✓ PASS: Error messages displayed for invalid inputs
✗ FAIL: Any deviation from expected results
