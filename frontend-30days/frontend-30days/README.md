## 🎯 How to Use This Course

### Prerequisites
- Code Editor: VS Code (recommended)
- Browser: Chrome or Firefox
- Node.js 14+ (for React projects)

### Installation & Setup

1. **For HTML/CSS/Vanilla JS projects:**
   - Open the HTML file directly in your browser
   - Or use Live Server extension in VS Code

2. **For React projects:**
   ```bash
   # Create a new React app
   npx create-react-app my-react-app
   cd my-react-app
   
   # Copy React component files to src/
   # Then run:
   npm start
   ```

3. **Using Vite (Faster alternative):**
   ```bash
   npm create vite@latest my-react-app -- --template react
   cd my-react-app
   npm install
   npm run dev
   ```

## 🔧 Troubleshooting

### HTML/CSS/JS Not Displaying?
- Ensure file paths are correct
- Check browser console for errors (F12)
- Clear browser cache (Ctrl+Shift+Delete)

### React Components Not Working?
- Verify Node.js is installed: `node --version`
- Check all dependencies are installed: `npm install`
- Look for errors in terminal and console
- Ensure components are properly exported/imported

### Styling Not Applied?
- Check CSS file is linked correctly
- Verify selectors match your HTML
- Use browser DevTools to inspect elements
- Check for conflicting CSS rules
