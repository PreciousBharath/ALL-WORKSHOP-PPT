Day 14 - JavaScript Basics

Variables, Data Types & Operators

Open the browser console (F12 or Right-click → Inspect → Console) to see the output.

Topics Covered:

  • Variables: var, let, const
  • Data Types: String, Number, Boolean, Object, Array, Null, Undefined
  • Arithmetic Operators: +, -, *, /, %, **
  • Assignment Operators: =, +=, -=, *=, /=
  • Comparison Operators: ==, ===, !=, !==, <, >, <=, >=
  • Logical Operators: &&, ||, !
  • String Operations: Concatenation, Template Literals

Key Takeaways:

  1. Use const by default, let when needed to reassign
  2. Use === for strict equality comparison
  3. Template literals with backticks are more readable than concatenation
  4. typeof operator helps identify data types
