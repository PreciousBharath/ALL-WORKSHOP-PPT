HTML BASICS - 20 PROGRAMS WITH LINE-BY-LINE EXPLANATIONS
========================================================

FORMAT USED FOR EVERY PROGRAM
1. Complete program
2. Line-by-line explanation in very simple English
3. Short result/what to observe

PROGRAM 1: Basic HTML Page
--------------------------

COMPLETE CODE:
<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello HTML</h1>
    <p>This is my first web page.</p>
</body>
</html>

LINE-BY-LINE EXPLANATION:
Line 1: <!DOCTYPE html>
Explanation: Declares that this document uses HTML5.
Line 2: <html>
Explanation: Starts the main HTML document.
Line 3: <head>
Explanation: Starts the section that stores page information.
Line 4:     <title>My First Page</title>
Explanation: Sets the text shown on the browser tab.
Line 5: </head>
Explanation: Closes the head section.
Line 6: <body>
Explanation: Starts the visible part of the page.
Line 7:     <h1>Hello HTML</h1>
Explanation: Creates a large main heading.
Line 8:     <p>This is my first web page.</p>
Explanation: Creates a paragraph of normal text.
Line 9: </body>
Explanation: Closes the body section.
Line 10: </html>
Explanation: Closes the HTML document.

RESULT / WHAT TO OBSERVE:
The browser shows a heading and a paragraph.

PROGRAM 3: Text Formatting
--------------------------

COMPLETE CODE:
<!DOCTYPE html>
<html>
<body>
    <p><strong>Important</strong> text</p>
    <p><em>Emphasized</em> text</p>
    <p><mark>Highlighted</mark> text</p>
    <p>H<sub>2</sub>O</p>
    <p>10<sup>2</sup></p>
</body>
</html>

LINE-BY-LINE EXPLANATION:
Line 1: <!DOCTYPE html>
Explanation: Declares HTML5.
Line 2: <html>
Explanation: Starts the document.
Line 3: <body>
Explanation: Starts visible content.
Line 4:     <p><strong>Important</strong> text</p>
Explanation: Creates a paragraph; strong marks Important as important text, then normal text follows.
Line 5:     <p><em>Emphasized</em> text</p>
Explanation: Creates a paragraph; em gives emphasized meaning to the word.
Line 6:     <p><mark>Highlighted</mark> text</p>
Explanation: Creates a paragraph; mark highlights the word.
Line 7:     <p>H<sub>2</sub>O</p>
Explanation: Creates a paragraph; sub places the number 2 below the normal text.
Line 8:     <p>10<sup>2</sup></p>
Explanation: Creates a paragraph; sup places 2 above the normal text.
Line 9: </body>
Explanation: Closes the body.
Line 10: </html>
Explanation: Closes the document.

RESULT / WHAT TO OBSERVE:
The words and numbers appear with different text formatting.
